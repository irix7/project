# GCC 16.2 primary, derived from the pdaxrom 15.2 IRIX port

The published patch series targets GCC 16.2 (15.3 as fallback) and is re-derived from `pdaxrom/irix-gcc`'s 15.2 IRIX diff onto the upstream 16.2 tag, with SGUG RSE and onre's `irix/gcc-9.2.0` as the GPL lineage and semantic oracle for triage. 15.2 is one release from 16.2; the proven public baseline is seven, and the patches are GPL by inheritance while no SGI-derived material is published.

**Consequences**: GCC internal churn between 15.2 and 16.2 may invalidate diff hunks, so the port re-derives changes rather than cherry-picking.
