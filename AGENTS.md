# SGI IRIX Toolchain

A toolchain and rebuild project for IRIX 6.5.7m on the SGI Indy: reproduce the operating system privately with GCC 16.2, then modernise it. Vocabulary lives in `CONTEXT.md`; decisions in `docs/adr/`.
